# Candidate demonstration outline

Target: 6 to 8 minutes. This is an outline to rehearse, not a statement that the candidate already understands or personally authored every component. The included captioned visual walkthrough uses actual browser screens in local evidence mode. Re-record with your own explanation if the employer expects a personal narrated demonstration.

| Time | Action and explanation |
|---|---|
| 0:00–0:40 | Introduce the scope: one local FastAPI service, SQLite, two specialist advisors and a general assistant. Disclose Codex assistance and identify your actual contributions. State whether AI mode is connected. |
| 0:40–1:35 | Administrator: calculate Q3 gross margin. Explain `(1,200,000 − 720,000) / 1,200,000 × 100 = 40%`. Show the warning about the source's wrong 45% and open a citation. |
| 1:35–2:10 | Compare Q2/Q3 revenue. Show 20% growth, the code formula and references to both periods. |
| 2:10–3:10 | Ask annual leave, then remote work. Show 24 days, then the 2-vs-3-day conflict. Explain that no precedence rule is configured. |
| 3:10–3:35 | Ask parental leave. Explain why no source is better than an invented policy. |
| 3:35–4:35 | Upload `finance_Q4.pdf` as Finance/Shared. Show the completed database summary and calculate Q4 gross margin (46%). Optionally upload the Word training policy and ask about its budget. |
| 4:35–5:40 | As Administrator retrieve the synthetic executive salary. Sign out; use Standard User and repeat. Show insufficient evidence, a filtered library and 404 for the same source ID. Explain server-side filtering before retrieval/provider calls. |
| 5:40–6:30 | Show the test command and actual results. Point out API timeout/error fallback, processing failures/retry, financial edge cases and access tests. These failures are test-injected, not decorative status cards. |
| 6:30–7:30 | Open the architecture diagram. Explain HTTPS, secure cookies, secret management, monitoring, backups and a future isolated parser/queue. End with clear limits and your actual contribution statement. |

For a source-ID access demonstration, use the ID returned by the admin source document request; do not infer or expose a secret through a new Standard-User metadata endpoint. The automated security suite checks this path without adding such an endpoint.
