Understand the two modes

Without an API key, Northstar uses lexical retrieval and exact source excerpts. With OPENAI_API_KEY configured on the server, the language model selects relevant quotes that are validated against the retrieved text. Financial calculations always run in Python. Conflict detection supports labelled HR facts; it does not resolve arbitrary contradictory prose.

Failure checks

The included automated tests exercise API failure, corrupt uploads, job failure and retry, access denial, zero denominators, and incorrect reported margins. The README includes commands and the recorded test results.

Recent system activity

Administrator only. Logs contain event metadata, without question text or document content.
